## Focus

- 센서융합과 상태추정: 카메라, 2D 라이다, IMU, DQN, IMM, Kalman Filter
- 자율주행과 경로계획: 객체 인지, Frenet, A-star, Dynamic VO, Pure Pursuit
- 임베디드와 시스템 소프트웨어: STM32, FreeRTOS, TouchGFX, ROS 2, WPF
